Overview

About

Admin tools help you operate and debug The Box outside the retro Ceefax viewer (Pages 100–400). They use the same HTTP API as the main app.

Tools

  • Settings

    Global server, schedule, ads, transcode, and library options stored in the SQLite app_settings table.

  • Channels

    Create, edit, and delete channels in the SQLite catalogue; rescan media and rebuild schedules.

  • Schedule inspector

    Full playback timeline for one channel: programme segments, commercial breaks, and idents (including items hidden from the TV guide and Today list).

  • Transcode cache lookup

    Map a cached {hash}.mp4 file back to programme rows in the database.
